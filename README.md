## 🛡️ About Me

안녕하세요,  
**공격자보다 한 발 앞선 사고로 문제를 해결하는 보안 엔지니어** 박기민입니다.

저는 **침해 탐지, 취약점 분석, 로그 기반 추적, 실전 대응**을 주도적으로 수행하며,  
**CTF, Wargame, 네트워크 실습, 데이터베이스 보안 분석** 등 다양한 분야의 실습을 통해 보안 역량을 체계적으로 쌓아왔습니다.

GitHub에는 다음과 같은 프로젝트들을 기록하고 있습니다:

**기술적 실전감각과 사고력 중심의 보안 전문가**로 성장하고 있습니다.
